## v6 做了什么

v6 不推翻 v5.2 的诊断框架，而是从它的内部矛盾生长出新问题。三个应用测试
（台湾芯片中断、东南亚美元融资断裂、全球债务同步崩溃）显示：框架的置信区间
随冲击范围扩大而系统性上升，直到在系统级冲击中失效——原因不在数据，而在
一个被隐藏的变量：**时间**。

## 核心变量

- **时间错配**：τ = T_min / T_available（定义 12.2）
- **可控性**：C = T_policy / T_threat = 1/τ（定义 13.1）
- **有效适应能力**：AC_有效 = AC_名义 × min(1, C)（式 11.3 / G.2）
- **社会学母题**：时间结构与制度结构的永久错配（定义 14.3）
