```
- κ₁ = 进口来源多元化（进口国数量vs单一供应商依赖）
- κ₂ = 贸易伙伴依赖（A国对B国的进口占A国进口的比例）
- κ₃ = 气候联动（主要产粮国的产量相关系数）
```

### 定义ι（归因一致性）的代理
```
- ι₁ = 国际粮食安全协议的签署率
- ι₂ = 粮食短缺时各国政策协调度（WTO协议遵守率）
```

### 计算V（脆弱性指标）
```
V = w₁·Θ + w₂·I + w₃·κ - w₄·ι

权重通过机制强度推导，不是拟合：
- 权力越集中（Θ大）+ 反馈越慢（I大）+ 耦合越强（κ大）
  → 系统脆弱性越高
- 共识越好（ι大）→ 抗击风险能力越强
```

## 三、四个核心变量的具体设计

### **Θ：权力集中（Agriculture Power Concentration）**

**含义**：粮食生产与供应的控制权集中程度。一个国家的粮食系统权力越集中，面对外部冲击时越缺乏备选方案。

| 代理变量 | 公式/数据来源 | 含义 | 0-1标准化方法 |
|---------|---------|------|-------------|
| $\theta_1$: 产量集中度 | Herfindahl index of domestic production (4作物) | 国内粮食生产是否依赖少数几种作物 | $HHI = \sum_i (p_i/P_{total})^2$ |
| $\theta_2$: 地域集中度 | 前3大产区产量占比 | 生产地理位置是否高度集中 | 比例直接使用 (0-100%) |
| $\theta_3$: 进口依赖度 | $\frac{\text{Import Quantity}}{\text{Domestic Consumption}}$ | 对国际市场的依赖程度 | 按百分比 (0-100%) |
| $\theta_4$: 进口供应商集中度 | HHI of import partners | 进口是否依赖少数几个出口国 | $HHI$ 直接使用 |
| $\theta_5$: 企业/农民集中度 | Gini index of farm sizes (World Bank) | 农业生产是否集中在大农场 | Gini直接使用 (0-1) |

**Θ的复合指标**：
$$M_{\Theta} = \frac{\theta_1 + \theta_2 + \theta_3 + \theta_4 + \theta_5}{5}$$

**机制强度权重 $w_{\Theta}$**：
- **为什么权力集中导致脆弱性？** 当粮食系统的控制权（生产、进口、贸易）集中时，系统对黑天鹅事件的缓冲能力最低。历史案例：2008年食品危机时，依赖少数供应商的国家受损最重。
- **权重建议**：$w_{\Theta} = 0.35$（最强的机制）

---

### **I：反馈延迟（Institutional Response Lag）**

**含义**：从粮食危机信号出现到制度反应的时间差。延迟越长，脆弱性越高。

| 代理变量 | 公式/数据来源 | 含义 | 0-1标准化方法 |
|---------|---------|------|-------------|
| $i_1$: 库存周转率 | $\frac{\text{Annual Consumption}}{\text{Ending Stock}}$ (年数) | 库存能支撑多少个月的消费 | 逆向：$1 - \min(\text{months}/12, 1)$ |
| $i_2$: 价格波动周期 | Coefficient of Variation of annual prices (最近10年) | 价格变化频率和幅度 | $CV = \frac{\sigma_{price}}{\mu_{price}}$ 直接用 |
| $i_3$: 贸易流波动性 | CV of import volumes (最近10年) | 进口数量的稳定性 | $CV$ 直接用 |
| $i_4$: 政策响应时间 | 灾害到政策出台的平均月数 | 决策延迟（难以量化，用代理） | 用**贸易协议更新频率**代理：年均协议变更数 |
| $i_5$: 库存变异率 | $\frac{\sigma(\text{Stock Variation})}{\mu(\text{Stock})}$ | 库存调整的稳定性 | $CV$ 直接用 |

**I的复合指标**：
$$M_I = \frac{i_1 + i_2 + i_3 + i_4 + i_5}{5}$$

**机制强度权重 $w_I$**：
- **为什么反馈延迟导致脆弱性？** 供给冲击（干旱、出口禁令）→ 库存下降 → 价格上升 → 社会骚乱，这个链条中每一步的延迟都会放大系统风险。
- **权重建议**：$w_I = 0.30$

---

### **κ：耦合度（Systemic Coupling）**

**含义**：粮食系统与其他系统的依赖程度。耦合越紧密，一个系统的崩溃越容易传导到粮食系统。

| 代理变量 | 公式/数据来源 | 含义 | 0-1标准化方法 |
|---------|---------|------|-------------|
| $\kappa_1$: 进口伙伴多元化 | $\frac{1}{\text{effective number of trading partners}}$ | 进口是否分散到多个国家 | $\frac{1}{\sum_j p_j^2}$，逆向标准化 |
| $\kappa_2$: 出口伙伴多元化 | 同上 | 出口市场分散度 | 同上 |
| $\kappa_3$: 地缘政治耦合 | 与进口国之间的地缘冲突指数 (World Bank Fragility Index) | 进口来源国的政治稳定性 | 平均Fragility Index (0-1) |
| $\kappa_4$: 气候脆弱性耦合 | 主要产区的降水变异系数 | 主要产地是否容易受极端气候影响 | $CV$ 直接用 |
| $\kappa_5$: 能源耦合 | 农业能源投入/总产出比 (World Bank) | 农业对化肥、燃料的依赖度 | 比例 (0-1) |

**κ的复合指标**：
$$M_{\kappa} = \frac{\kappa_1 + \kappa_2 + \kappa_3 + \kappa_4 + \kappa_5}{5}$$

**机制强度权重 $w_{\kappa}$**：
- **为什么耦合导致脆弱性？** 2022年乌克兰危机中，依赖俄罗斯、乌克兰进口且地缘政治对立的国家受损最重。能源危机也通过农业生产成本传导到粮食安全。
- **权重建议**：$w_{\kappa} = 0.20$

---

### **ι：归因一致性（Attribution Consistency）**

**含义**：粮食安全问题的定义、测量、解决方案是否跨国家形成共识。共识越低，国际合作越困难，应对危机的能力越弱。

| 代理变量 | 公式/数据来源 | 含义 | 0-1标准化方法 |
|---------|---------|------|-------------|
| $\iota_1$: 国际协议签署率 | 签署粮食安全相关条约数 / 已签条约总数 (WTO, FAO) | 制度层面的共识 | 比例 (0-1) |
| $\iota_2$: 贸易保护主义指数 | 平均关税税率 + 贸易壁垒数量 | 国家间的贸易共识 | 逆向标准化 |
| $\iota_3$: 信息透明度 | 粮食价格、库存公开数据的可获得度 | 系统内的信息对称性 | 根据有无统计能力 (0/0.5/1) |
| $\iota_4$: 食品支出占比 | 低收入家庭食品支出 / 总支出 | 社会对粮食问题的共识敏感度 | 比例 (0-1)，越高越脆弱 |
| $\iota_5$: 政策协调度 | 国家政策与FAO/WFP建议的一致性指数 | 国际指导的接纳程度 | (0-1) |

**ι的复合指标**：
$$M_{\iota} = 1 - \frac{\iota_1 + (1-\iota_2) + \iota_3 + \iota_4 + \iota_5}{5}$$

（注：$\iota_2$反向，因为贸易保护主义高意味着一致性低）

**机制强度权重 $w_{\iota}$**：
- **为什么归因不一致导致脆弱性？** 2008年危机中，各国对"根本原因"（投机vs供给不足）的理解不同，导致合作延迟。
- **权重建议**：$w_{\iota} = 0.15$

```python
                consumption = self.balances[
                    (self.balances['Country'] == country) &
                    (self.balances['Year'] == year)
                ]['Food supply (kcal/capita/day)'].sum()
                import_dep = imports / (total_prod + imports) if (total_prod + imports) > 0 else 0
                
                # θ4: 进口供应商集中度
                import_partners = self.trade[
                    (self.trade['Reporter Country'] == country) &
                    (self.trade['Year'] == year) &
                    (self.trade['Trade Flow'] == 'Import')
                ]
                partner_shares = import_partners.groupby('Partner Country')['Value'].sum() / imports
                hhi_partners = (partner_shares**2).sum() if imports > 0 else 0
                
                # θ5: 企业集中度（用Gini代理）
                gini_farms = self._get_gini_farm_size(country, year)
                
                # 汇总
                theta = (hhi_prod + regional_conc + import_dep + hhi_partners + gini_farms) / 5
                results[(country, year)] = theta
        
        return results
    
    # ============ 阶段2b：I计算 ============
    def calculate_I(self):
        """反馈延迟"""
        results = {}
        
        for country in self.countries:
            for year in self.years:
                # i1: 库存周转率
                stock = self.balances[
                    (self.balances['Country'] == country) &
                    (self.balances['Year'] == year)
                ]['Ending Stocks'].sum()
                consumption = self.balances[
                    (self.balances['Country'] == country) &
                    (self.balances['Year'] == year)
                ]['Food supply (kcal/capita/day)'].sum()
                stock_months = (stock / consumption * 365 / 30) if consumption > 0 else 0
                i1 = 1 - min(stock_months / 12, 1)  # 12个月为满分
                
                # i2: 价格波动（最近10年CV）
                price_window = self.prices[
                    (self.prices['Country'] == country) &
                    (self.prices['Year'] >= year - 10) &
                    (self.prices['Year'] <= year)
                ]['Value']
                i2 = price_window.std() / price_window.mean() if price_window.mean() > 0 else 0
                
                # i3: 进口波动性
                import_window = self.trade[
                    (self.trade['Reporter Country'] == country) &
                    (self.trade['Year'] >= year - 10) &
                    (self.trade['Year'] <= year) &
                    (self.trade['Trade Flow'] == 'Import')
                ]['Value']
                i3 = import_window.std() / import_window.mean() if import_window.mean() > 0 else 0
                
                # i4: 政策更新频率（需额外数据，暂用0.5代理）
                i4 = 0.5
                
                # i5: 库存变异率
                stock_var_window = self.balances[
                    (self.balances['Country'] == country) &
                    (self.balances['Year'] >= year - 10) &
                    (self.balances['Year'] <= year)
                ]['Stock Variation']
                i5 = stock_var_window.std() / abs(stock_var_window.mean()) if stock_var_window.mean() != 0 else 0
                
                I = (i1 + i2 + i3 + i4 + i5) / 5
                results[(country, year)] = I
        
        return results
    
    # ============ 阶段2c：κ计算 ============
    def calculate_kappa(self):
        """耦合度"""
        results = {}
        
        for country in self.countries:
            for year in self.years:
                # κ1: 进口伙伴多元化
                import_data = self.trade[
                    (self.trade['Reporter Country'] == country) &
                    (self.trade['Year'] == year) &
                    (self.trade['Trade Flow'] == 'Import')
                ]
                if len(import_data) > 0:
                    shares = import_data.groupby('Partner Country')['Value'].sum()
                    shares = shares / shares.sum()
                    kappa1 = 1 / (shares**2).sum()  # 有效伙伴国数
                else:
                    kappa1 = 0
                
                # κ2: 出口伙伴多元化（同理）
                export_data = self.trade[
                    (self.trade['Reporter Country'] == country) &
                    (self.trade['Year'] == year) &
                    (self.trade['Trade Flow'] == 'Export')
                ]
                kappa2 = self._calc_export_diversity(export_data)
                
                # κ3: 地缘政治耦合（需World Bank数据）
                kappa3 = self._get_geopolitical_coupling(country, year)
                
                # κ4: 气候脆弱性（需气候数据）
                kappa4 = self._get_climate_vulnerability(country, year)
                
                # κ5: 能源耦合（需农业投入数据）
                kappa5 = self._get_energy_coupling(country, year)
                
                kappa = (kappa1 + kappa2 + kappa3 + kappa4 + kappa5) / 5
                results[(country, year)] = kappa
        
        return results
    
    # ============ 阶段2d：ι计算 ============
    def calculate_iota(self):
        """归因一致性"""
        results = {}
        
        for country in self.countries:
            for year in self.years:
                # ι1: 国际协议签署率
                iota1 = self._get_treaty_compliance(country, year)
                
                # ι2: 贸易保护主义（需WTO数据）
                iota2_protection = self._get_tariff_level(country, year)
                iota2 = 1 - iota2_protection  # 逆向
                
                # ι3: 信息透明度
                iota3 = self._get_transparency(country, year)
                
                # ι4: 食品支出占比
                iota4 = self._get_food_expense_share(country, year)
                
                # ι5: 政策协调度
                iota5 = self._get_policy_alignment(country, year)
                
                iota = 1 - (iota1 + iota2 + iota3 + iota4 + iota5) / 5
                results[(country, year)] = iota
        
        return results
    
    # ============ 阶段3：权重设定（从机制推导，不拟合）============
    def calculate_vulnerability(self, theta_results, I_results, kappa_results, iota_results):
        """
        计算最终脆弱性指标V
        
        权重设定原理：
        - w_Θ = 0.35：权力集中是最根本的脆弱性根源
        - w_I = 0.30：反馈延迟放大风险传导
        - w_κ = 0.20：耦合决定冲击范围
        - w_ι = 0.15：共识不足阻碍国际合作
        """
        
        weights = {'theta': 0.35, 'I': 0.30, 'kappa': 0.20, 'iota': 0.15}
        
        # 验证权重和为1
        assert sum(weights.values()) == 1.0, "权重必须和为1"
        
        vulnerability = {}
        
        for country in self.countries:
            for year in self.years:
                key = (country, year)
                
                # 标准化各指标到0-1
                M_theta = min(max(theta_results[key], 0), 1)
                M_I = min(max(I_results[key], 0), 1)
                M_kappa = min(max(kappa_results[key], 0), 1)
                M_iota = min(max(iota_results[key], 0), 1)
                
                # 计算脆弱性
                V = (weights['theta'] * M_theta + 
                     weights['I'] * M_I + 
                     weights['kappa'] * M_kappa + 
                     weights['iota'] * M_iota)
                
                vulnerability[key] = {
                    'V_total': V,
                    'M_theta': M_theta,
                    'M_I': M_I,
                    'M_kappa': M_kappa,
                    'M_iota': M_iota,
                    'country': country,
                    'year': year
                }
        
        return vulnerability
    
    # ============ 阶段4：结果验证 ============
    def validate_results(self, vulnerability):
        """
        验证脆弱性排序是否符合直觉：
        - 俄罗斯/乌克兰（2022年后）应排名靠后（脆弱）
        - 中国应排名较高（相对稳定）
        - 印度应中等（高产量但高依赖）
        """
        
        df = pd.DataFrame([v for v in vulnerability.values()])
        
        # 2022年各国排序
        ranking_2022 = df[df['year'] == 2022].sort_values('V_total', ascending=False)
        
        print("=== 2022年粮食系统脆弱性排序 ===")
        print(ranking_2022[['country', 'V_total', 'M_theta', 'M_I', 'M_kappa', 'M_iota']])
        
        # 敏感性分析：权重改变对排序的影响
        self._sensitivity_analysis(vulnerability)
        
        return ranking_2022
    
    def _sensitivity_analysis(self, vulnerability):
        """检查排序稳定性"""
        print("\n=== 敏感性分析：权重变化对排序的影响 ===")
        
        # 尝试改变权重，看排序是否稳定
        alternative_weights = [
            {'theta': 0.40, 'I': 0.25, 'kappa': 0.20, 'iota': 0.15},
            {'theta': 0.30, 'I': 0.35, 'kappa': 0.20, 'iota': 0.15},
            {'theta': 0.35, 'I': 0.30, 'kappa': 0.25, 'iota': 0.10},
        ]
        
        for w in alternative_weights:
            df = pd.DataFrame([v for v in vulnerability.values()])
            df['V_alt'] = (w['theta'] * df['M_theta'] + 
                          w['I'] * df['M_I'] + 
                          w['kappa'] * df['M_kappa'] + 
                          w['iota'] * df['M_iota'])
            
            ranking_alt = df[df['year'] == 2022][['country', 'V_alt']].sort_values('V_alt', ascending=False)
            print(f"\n权重 {w}:")
            print(ranking_alt)
```

```python
        # 标准化GNI
        wb_df['GNI_normalized'] = (wb_df['GNI_per_capita'] - wb_df['GNI_per_capita'].min()) / \
                                   (wb_df['GNI_per_capita'].max() - wb_df['GNI_per_capita'].min())
        
        # Gini Index已有（用作贫困代理）
        wb_df['Gini_normalized'] = wb_df['Gini_Index'] / 100
        
        # 计算食品支出占比
        wb_df['Food_Expense_Share'] = (1 - wb_df['GNI_normalized']) * 0.4 + \
                                      wb_df['Gini_normalized'] * 0.6
        
        return wb_df[['Country', 'Year', 'Food_Expense_Share']]

        # 1. World Bank

        # 3. AQUASTAT
        aquastat_df = self.download_aquastat_data()
        
        # 4. Comtrade

        # 5. 推导食品支出占比

        food_expense.to_csv(self.output_dir / "Derived_Food_Expense_Share.csv", index=False)

        return {
            'world_bank': wb_df,
            'aquastat': aquastat_df,
            'food_expense': food_expense
        }
```

```python
    def _calculate_theta(self, production_df, trade_df):
        """
        Θ = (产量集中度 + 进口依赖度 + 进口伙伴集中度) / 3
        """
        theta_results = []
        
        # 清洁数据
        prod = production_df[production_df['Value'] > 0].copy()
        prod['Country'] = prod.get('Area', '')
        prod['Year'] = prod.get('Year', 0)
        
        for country in self.countries.values():
            for year in self.years:
                # θ1: 产量集中度 (HHI of 4 crops)
                country_year_prod = prod[
                    (prod['Country'] == country) & 
                    (prod['Year'] == year)
                ]
                
                if len(country_year_prod) > 0:
                    total = country_year_prod['Value'].sum()
                    shares = country_year_prod['Value'] / total
                    hhi_prod = (shares ** 2).sum()
                else:
                    hhi_prod = np.nan
                
                # θ2: 进口依赖度
                imports = trade_df[
                    (trade_df.get('Reporter Country', '') == country) &
                    (trade_df.get('Year', 0) == year) &
                    (trade_df.get('Trade Flow', '') == 'Import')
                ]['Value'].sum()
                
                domestic_prod = country_year_prod['Value'].sum()
                import_dep = imports / (domestic_prod + imports) if (domestic_prod + imports) > 0 else np.nan
                
                # θ3: 进口伙伴集中度
                import_partners = trade_df[
                    (trade_df.get('Reporter Country', '') == country) &
                    (trade_df.get('Year', 0) == year) &
                    (trade_df.get('Trade Flow', '') == 'Import')
                ]
                
                if imports > 0 and len(import_partners) > 0:
                    partner_shares = import_partners.groupby(
                        import_partners.get('Partner Country', '')
                    )['Value'].sum() / imports
                    hhi_partners = (partner_shares ** 2).sum()
                else:
                    hhi_partners = np.nan
                
                # 综合Θ
                theta = np.nanmean([hhi_prod, import_dep, hhi_partners])
                
                theta_results.append({
                    'Country': country,
                    'Year': year,
                    'Theta_HHI_Production': hhi_prod,
                    'Theta_Import_Dependency': import_dep,
                    'Theta_Partner_Concentration': hhi_partners,
                    'Theta_Combined': theta
                })
        
        return pd.DataFrame(theta_results)
    
    def _calculate_I(self, prices_df, balances_df):
        """
        I = (价格波动系数 + 库存波动系数) / 2
        """
        I_results = []
        
        for country in self.countries.values():
            for year in self.years:
                # I1: 价格波动 (CV of last 5 years)
                price_window = prices_df[
                    (prices_df.get('Area', '') == country) &
                    (prices_df.get('Year', 0) >= year - 5) &
                    (prices_df.get('Year', 0) <= year)
                ]['Value']
                
                if len(price_window) > 1:
                    price_cv = price_window.std() / price_window.mean() if price_window.mean() > 0 else np.nan
                else:
                    price_cv = np.nan
                
                # I2: 库存波动
                stock_window = balances_df[
                    (balances_df.get('Area', '') == country) &
                    (balances_df.get('Year', 0) >= year - 5) &
                    (balances_df.get('Year', 0) <= year)
                ]['Stock Variation']
                
                if len(stock_window) > 1:
                    stock_cv = stock_window.std() / abs(stock_window.mean()) if stock_window.mean() != 0 else np.nan
                else:
                    stock_cv = np.nan
                
                I = np.nanmean([price_cv, stock_cv])
                
                I_results.append({
                    'Country': country,
                    'Year': year,
                    'I_Price_CV': price_cv,
                    'I_Stock_CV': stock_cv,
                    'I_Combined': I
                })
        
        return pd.DataFrame(I_results)
    
    def _calculate_kappa(self, trade_df):
        """
        κ = 进口伙伴多元化程度 (有效伙伴国数)
        """
        kappa_results = []
        
        for country in self.countries.values():
            for year in self.years:
                import_data = trade_df[
                    (trade_df.get('Reporter Country', '') == country) &
                    (trade_df.get('Year', 0) == year) &
                    (trade_df.get('Trade Flow', '') == 'Import')
                ]
                
                if len(import_data) > 0:
                    total_imports = import_data['Value'].sum()
                    if total_imports > 0:
                        partner_shares = import_data.groupby(
                            import_data.get('Partner Country', '')
                        )['Value'].sum() / total_imports
                        # 有效伙伴国数 = 1 / HHI
                        hhi = (partner_shares ** 2).sum()
                        effective_partners = 1 / hhi if hhi > 0 else np.nan
                    else:
                        effective_partners = np.nan
                else:
                    effective_partners = np.nan
                
                kappa_results.append({
                    'Country': country,
                    'Year': year,
                    'Kappa_Import_Diversity': effective_partners
                })
        
        return pd.DataFrame(kappa_results)
    
    # ============ 步骤4：整合所有数据 ============
    def integrate_all_data(self, core_indicators, wb_data):

        整合FAOSTAT推导的指标 + World Bank指标

            if key in core_indicators:
                merged = merged.merge(
                    core_indicators[key],
                    on=['Country', 'Year'],
                    how='left'
                )
        
        # 合并World Bank数据
        if wb_data is not None:
            # 转换列名匹配
            wb_data['Country_Code'] = wb_data['Country_Code'].map({v: k for k, v in self.countries.items()})
            merged = merged.merge(
                wb_data,
                left_on=['Country', 'Year'],
                right_on=['Country', 'Country_Code', 'Year'],
                how='left'
            )
        
        # 保存
        output_path = self.output_dir / "Integrated_Food_Vulnerability_Data.csv"
        merged.to_csv(output_path, index=False)
        print(f"\n✓ 整合数据已保存: {output_path}")
        print(f"  总行数: {len(merged)}")
        print(f"  总列数: {len(merged.columns)}")
        
        return merged

    def run_complete_pipeline(self):
        """执行完整流程"""
```

```python
    def calculate_core_indicators_from_faostat(self, faostat_data):

        print("\n" + "=" * 70)
        print("【步骤3】从FAOSTAT数据推导指标")

    def _calculate_theta(self, production_df, trade_df):
        """
        Θ = (产量集中度 + 进口依赖度 + 进口伙伴集中度) / 3
        
        从FAOSTAT长格式数据中提取：
        - Production: Element == 'Production'
        - Import quantity: Element == 'Import quantity'
        """
        theta_results = []
        
        # 过滤粮食数据
        prod = production_df[
            (production_df['Area'].isin(self.countries)) &
            (production_df['Item'].isin(self.crops)) &
            (production_df['Element'] == 'Production') &
            (production_df['Year'].isin(self.years)) &
            (production_df['Value'] > 0)
        ].copy()
        
        trade = trade_df[
            (trade_df['Area'].isin(self.countries)) &
            (trade_df['Item'].isin(self.crops)) &
            (trade_df['Year'].isin(self.years))
        ].copy()
        
        for country in self.countries:
            for year in self.years:
                # θ1: 产量集中度 (HHI of 4 crops)
                country_year_prod = prod[
                    (prod['Area'] == country) & 
                    (prod['Year'] == year)
                ]
                
                if len(country_year_prod) > 0:
                    total = country_year_prod['Value'].sum()
                    shares = country_year_prod['Value'] / total
                    hhi_prod = (shares ** 2).sum()
                else:
                    hhi_prod = np.nan
                
                # θ2: 进口依赖度
                imports = trade[
                    (trade['Area'] == country) &
                    (trade['Year'] == year) &
                    (trade['Element'] == 'Import quantity')
                ]['Value'].sum()
                
                domestic_prod = country_year_prod['Value'].sum()
                total_supply = domestic_prod + imports
                import_dep = imports / total_supply if total_supply > 0 else np.nan
                
                # θ3: 进口伙伴集中度 (HHI)
                import_data = trade[
                    (trade['Area'] == country) &
                    (trade['Year'] == year) &
                    (trade['Element'] == 'Import quantity')
                ]
                
                if len(import_data) > 0 and imports > 0:
                    partner_shares = import_data.groupby('Item')['Value'].sum() / imports
                    hhi_partners = (partner_shares ** 2).sum()
                else:
                    hhi_partners = np.nan
                
                # 综合Θ (只取有效值求平均)
                theta_values = [v for v in [hhi_prod, import_dep, hhi_partners] if not np.isnan(v)]
                theta = np.mean(theta_values) if theta_values else np.nan
                
                theta_results.append({
                    'Country': country,
                    'Year': year,
                    'Theta_HHI_Production': hhi_prod,
                    'Theta_Import_Dependency': import_dep,
                    'Theta_Partner_Concentration': hhi_partners,
                    'Theta_Combined': theta
                })
        
        return pd.DataFrame(theta_results)
    
    def _calculate_I(self, prices_df):
        """
        I = 价格波动系数 (Coefficient of Variation)
        
        从FAOSTAT价格数据计算最近10年的价格波动
        """
        I_results = []
        
        prices = prices_df[
            (prices_df['Area'].isin(self.countries)) &
            (prices_df['Item'].isin(self.crops)) &
            (prices_df['Element'] == 'Producer Price (LCU/tonne)') &
            (prices_df['Value'] > 0)
        ].copy()
        
        for country in self.countries:
            for year in self.years:
                # 计算过去10年的价格波动
                price_window = prices[
                    (prices['Area'] == country) &
                    (prices['Year'] >= year - 10) &
                    (prices['Year'] <= year)
                ]['Value']
                
                if len(price_window) > 2:  # 至少要有3个数据点
                    mean_price = price_window.mean()
                    if mean_price > 0:
                        price_cv = price_window.std() / mean_price
                    else:
                        price_cv = np.nan
                else:
                    price_cv = np.nan
                
                I_results.append({
                    'Country': country,
                    'Year': year,
                    'I_Price_CV': price_cv,
                    'I_Combined': price_cv  # 简化版本，只用价格波动
                })
        
        return pd.DataFrame(I_results)
    
    def _calculate_kappa(self, trade_df):
        """
        κ = 进口伙伴多元化程度 (有效伙伴国数)
        
        κ = 1 / HHI_partners
        """
        kappa_results = []
        
        trade = trade_df[
            (trade_df['Area'].isin(self.countries)) &
            (trade_df['Item'].isin(self.crops)) &
            (trade_df['Element'] == 'Import quantity') &

        ].copy()
        
        for country in self.countries:
            for year in self.years:

                    (trade['Area'] == country) &
                    (trade['Year'] == year)
                ]

                    total_imports = import_data['Value'].sum()

                        # 按商品项目计算多元化
                        item_shares = import_data.groupby('Item')['Value'].sum() / total_imports
                        hhi = (item_shares ** 2).sum()
                        # 有效商品种类数
                        effective_diversity = 1 / hhi if hhi > 0 else np.nan
                    else:
                        effective_diversity = np.nan
                else:
                    effective_diversity = np.nan
                
                kappa_results.append({
                    'Country': country,
                    'Year': year,
                    'Kappa_Import_Diversity': effective_diversity
                })
        
        return pd.DataFrame(kappa_results)
```

```python
                min_val = df[indicator].min()
                max_val = df[indicator].max()
                
                if max_val > min_val:
                    df_normalized[f'{indicator}_norm'] = (df[indicator] - min_val) / (max_val - min_val)
                else:
```

## 二、建议的验证口径

### 1）Θ：权力集中度
用以下代理变量：
- 能源进口依赖度
- 能源产出集中度
- 出口集中度

如果你现在没有双边贸易细节，就先用：
- **进口依赖度**作为 Θ 的主项
- 再结合油气生产规模的反向项

### 2）I：反馈延迟
用：
- 价格波动强度
- 产量波动强度

如果没有月度价格序列，就先用：
- 年度变化率的标准差
- 或快速验证集里的产量波动

### 3）κ：耦合度
用：
- 进口依赖
- 能源贸易集中度
- 供应来源多样性

如果你暂时没有贸易伙伴数据，可以先用：
- World Bank 能源依赖度
- 快速验证中的出口/进口能力反向表示

### 4）V：总脆弱性
建议先用一个透明的线性加权：

\[
V = 0.4\Theta + 0.35I + 0.25\kappa
\]

这是和你之前粮食系统验证保持一致的结构，便于论文里做跨域对照。

## 三、我建议你现在直接跑的计算脚本

下面这个脚本可以直接读你上传的数据文件，计算一个**验证版能源脆弱性指数**。

```python
import pandas as pd
import numpy as np
from pathlib import Path

# ------------------------
# 1. 读取数据
# ------------------------
wb_path = Path("/mnt/data/file-ATmKkcxeE52JWuotNrUAv7-WorldBank_Energy_Indicators.csv")
quick_path = Path("/mnt/data/file-LU9SVNVHJ1rLCcu4vqhdNF-02_Quick_Validation_Dataset.csv")

wb = pd.read_csv(wb_path)
quick = pd.read_csv(quick_path)

print("World Bank rows:", len(wb))
print("Quick validation rows:", len(quick))
print("\nWorld Bank columns:", wb.columns.tolist())
print("Quick columns:", quick.columns.tolist())

# ------------------------
# 2. 清洗World Bank数据
# ------------------------
wb["Year"] = pd.to_numeric(wb["Year"], errors="coerce")
wb["Value"] = pd.to_numeric(wb["Value"], errors="coerce")

# 透视表：Country-Year-Indicator
wb_pivot = wb.pivot_table(
    index=["Country", "Year"],
    columns="Indicator",
    values="Value",
    aggfunc="mean"
).reset_index()

print("\nWorld Bank pivot shape:", wb_pivot.shape)

# ------------------------
# 3. 对快速验证数据做标准化
# ------------------------
quick["Year"] = pd.to_numeric(quick["Year"], errors="coerce")

# 选取可用列
needed_cols = [
    "Country", "Year",
    "Oil_Production_MBPD", "Oil_Exports_MBPD",
    "Gas_Production_BCM", "Gas_Exports_BCM"
]
quick = quick[needed_cols].copy()

for col in needed_cols[2:]:
    quick[col] = pd.to_numeric(quick[col], errors="coerce")

# ------------------------
# 4. 构造指标
# ------------------------

# Θ：权力集中度
# 逻辑：进口依赖越高 -> 越脆弱；油气出口能力越强 -> 越不脆弱
# 为了统一方向，做一个简单映射：
# Theta = 进口依赖度标准化 + 生产集中风险
def minmax(s):
    s = pd.to_numeric(s, errors="coerce")
    if s.notna().sum() == 0:
        return s
    return (s - s.min()) / (s.max() - s.min()) if s.max() != s.min() else s*0

# 从World Bank中拿能源进口依存度
theta_df = wb_pivot.copy()

# 找到最接近“进口依赖”的列名
print("\nWB available indicators:", [c for c in theta_df.columns if c not in ["Country", "Year"]])

# 自动匹配
import_col = None
for c in theta_df.columns:
    if "Import" in c or "Dependency" in c:
        import_col = c
        break

if import_col is None:
    raise ValueError("未找到能源进口依赖列，请检查World Bank数据中的Indicator名称。")

theta_df["Theta_Import_Dependency"] = theta_df[import_col]
theta_df["Theta_Import_Dependency_N"] = theta_df.groupby("Year")["Theta_Import_Dependency"].transform(minmax)

# 用快速验证数据补一个“生产安全”项
prod = quick.copy()
prod["Total_Production"] = prod["Oil_Production_MBPD"].fillna(0) + prod["Gas_Production_BCM"].fillna(0)

prod["Production_Security_N"] = prod.groupby("Year")["Total_Production"].transform(minmax)
prod["Production_Risk_N"] = 1 - prod["Production_Security_N"]

# 合并
df = pd.merge(theta_df[["Country", "Year", "Theta_Import_Dependency_N"]], prod[["Country", "Year", "Production_Risk_N"]],
              on=["Country", "Year"], how="outer")

# Θ 取两者平均
df["Theta"] = df[["Theta_Import_Dependency_N", "Production_Risk_N"]].mean(axis=1)

# I：反馈延迟/波动
# 这里先用生产波动近似
prod2 = quick.sort_values(["Country", "Year"]).copy()
for col in ["Oil_Production_MBPD", "Gas_Production_BCM"]:
    prod2[f"{col}_chg"] = prod2.groupby("Country")[col].pct_change()

prod2["I_raw"] = prod2[[c for c in prod2.columns if c.endswith("_chg")]].abs().mean(axis=1)
prod2["I"] = prod2.groupby("Year")["I_raw"].transform(minmax)

# κ：耦合度
# 暂用“出口能力越强、耦合越低”思想做近似
prod2["Export_Capacity"] = prod2["Oil_Exports_MBPD"].fillna(0) + prod2["Gas_Exports_BCM"].fillna(0)
prod2["Export_Capacity_N"] = prod2.groupby("Year")["Export_Capacity"].transform(minmax)
prod2["Kappa"] = 1 - prod2["Export_Capacity_N"]

# 合并 I 和 κ
df = pd.merge(df, prod2[["Country", "Year", "I", "Kappa"]], on=["Country", "Year"], how="outer")

# ------------------------
# 5. 计算总脆弱性 V
# ------------------------
df["V"] = 0.4 * df["Theta"] + 0.35 * df["I"] + 0.25 * df["Kappa"]

# ------------------------
# 6. 输出结果
# ------------------------
result = df.sort_values(["Year", "V"], ascending=[True, False])

print("\n=== 验证结果预览 ===")
print(result.head(20))

# 国家平均脆弱性
country_rank = df.groupby("Country", as_index=False)["V"].mean().sort_values("V", ascending=False)
print("\n=== 国家平均脆弱性排序 ===")
print(country_rank)

# 年度均值
year_trend = df.groupby("Year", as_index=False)["V"].mean().sort_values("Year")
print("\n=== 年度平均脆弱性趋势 ===")
print(year_trend)

# 保存
out1 = "/mnt/data/energy_vulnerability_verified.csv"
out2 = "/mnt/data/energy_vulnerability_country_rank.csv"
out3 = "/mnt/data/energy_vulnerability_year_trend.csv"

result.to_csv(out1, index=False)
country_rank.to_csv(out2, index=False)
year_trend.to_csv(out3, index=False)

print("\n已保存：")
print(out1)
print(out2)
print(out3)
```

```python
    def calculate_food_vulnerability(self):
        """
        基于现有粮食指标计算脆弱性指数 V_Food
        
        V_Food = 0.40*Theta_Food + 0.35*I_Food + 0.25*Kappa_Food
        
        （权重根据你的论文第7章设定）
        """
        print("\n【粮食系统】脆弱性指标计算")
        print("-"*70)
        
        df = self.data_dict['food_raw'].copy()
        
        # 处理缺失值
        for col in ['Theta_Food', 'I_Food', 'Kappa_Food']:
            if col in df.columns:
                df[col] = pd.to_numeric(df[col], errors='coerce')
        
        # 计算 V_Food（按照论文中的权重）
        # 如果某些分量缺失，使用可用的分量计算
        weights = {'Theta': 0.40, 'I': 0.35, 'Kappa': 0.25}
        
        def calc_v(row):
            components = {
                'Theta': row.get('Theta_Food'),
                'I': row.get('I_Food'),
                'Kappa': row.get('Kappa_Food')
            }
            
            # 过滤非缺失的分量
            valid = {k: v for k, v in components.items() if pd.notna(v)}
            
            if len(valid) == 0:
                return np.nan
            
            # 重新归一化权重
            total_weight = sum(weights[k] for k in valid.keys())
            if total_weight == 0:
                return np.nan
            
            v_value = sum(components[k] * weights[k] for k in valid.keys()) / total_weight
            return v_value
        
        df['V_Food'] = df.apply(lambda row: calc_v(row), axis=1)
        
        print(f"✓ V_Food 计算完成")
        print(f"  有效记录: {df['V_Food'].notna().sum()}")
        print(f"  V_Food 范围: {df['V_Food'].min():.3f} - {df['V_Food'].max():.3f}")
        
        self.data_dict['food_v'] = df[['Country', 'Year', 'Theta_Food', 'I_Food', 'Kappa_Food', 'V_Food']]
        return df

    def calculate_energy_vulnerability(self):
        """
        基于 World Bank 和产量数据计算能源脆弱性指标
        
        Θ_Energy: 进口依赖 + 生产集中度
        I_Energy: 产量波动 + (理想)价格波动
        κ_Energy: 出口集中 + 进口来源集中
        
        V_Energy = 0.40*Θ + 0.35*I + 0.25*κ
        """
        print("\n【能源系统】脆弱性指标计算")
        print("-"*70)
        
        wb_df = self.data_dict['energy_wb'].copy()
        prod_df = self.data_dict['energy_production'].copy()
        
        # 透视World Bank数据
        wb_pivot = wb_df.pivot_table(
            index=['Country', 'Year'],
            columns='Indicator',
            values='Value',
            aggfunc='mean'
        ).reset_index()
        
        # 标准化（0-1）函数
        def minmax_normalize(series):
            s = pd.to_numeric(series, errors='coerce')
            if s.notna().sum() == 0:
                return series * np.nan
            s_min, s_max = s.min(), s.max()
            if s_max == s_min:
                return s * 0.5
            return (s - s_min) / (s_max - s_min)
        
        # 计算能源Θ
        # Θ = 进口依赖度 + (1 - 生产安全)
        print("  计算 Θ (权力集中度)...")
        
        wb_pivot['Theta_Import_N'] = wb_pivot.groupby('Year')['Energy_Import_Dependency'].transform(minmax_normalize)
        
        # 从产量数据计算生产能力
        prod_pivot = prod_df.copy()
        prod_pivot['Total_Production'] = (
            prod_pivot['Oil_Production_MBPD'].fillna(0) + 
            prod_pivot['Gas_Production_BCM'].fillna(0) / 100  # 归一化
        )
        prod_pivot['Production_Security_N'] = prod_pivot.groupby('Year')['Total_Production'].transform(minmax_normalize)
        prod_pivot['Theta_Production_Risk_N'] = 1 - prod_pivot['Production_Security_N'].fillna(0.5)
        
        # 合并
        energy_df = pd.merge(
            wb_pivot[['Country', 'Year', 'Theta_Import_N']],
            prod_pivot[['Country', 'Year', 'Theta_Production_Risk_N']],
            on=['Country', 'Year'],
            how='outer'
        )
        
        energy_df['Theta_Energy'] = energy_df[[
            'Theta_Import_N', 'Theta_Production_Risk_N'
        ]].mean(axis=1)
        
        print(f"  ✓ Θ 计算完成: {energy_df['Theta_Energy'].notna().sum()} 条记录")
        
        # 计算能源I（波动）
        print("  计算 I (反馈延迟/波动)...")
        
        # 按国家计算产量的年度变化率
        prod_pivot_sorted = prod_pivot.sort_values(['Country', 'Year'])
        for col in ['Oil_Production_MBPD', 'Gas_Production_BCM']:
            prod_pivot_sorted[f'{col}_pct_change'] = prod_pivot_sorted.groupby('Country')[col].pct_change().abs()
        
        # I = 平均绝对变化率
        prod_pivot_sorted['I_raw'] = prod_pivot_sorted[[
            'Oil_Production_MBPD_pct_change', 'Gas_Production_BCM_pct_change'
        ]].mean(axis=1)
        prod_pivot_sorted['I_Energy'] = prod_pivot_sorted.groupby('Year')['I_raw'].transform(minmax_normalize)
        
        energy_df = pd.merge(
            energy_df,
            prod_pivot_sorted[['Country', 'Year', 'I_Energy']],
            on=['Country', 'Year'],
            how='outer'
        )
        
        print(f"  ✓ I 计算完成: {energy_df['I_Energy'].notna().sum()} 条记录")
        
        # 计算能源κ（耦合度）
        print("  计算 κ (耦合度)...")
        
        # κ = 1 - 出口能力（出口能力强 → 耦合弱）
        prod_pivot['Export_Capacity'] = (
            prod_pivot['Oil_Exports_MBPD'].fillna(0) + 
            prod_pivot['Gas_Exports_BCM'].fillna(0) / 100
        )
        prod_pivot['Export_Capacity_N'] = prod_pivot.groupby('Year')['Export_Capacity'].transform(minmax_normalize)
        prod_pivot['Kappa_Energy'] = 1 - prod_pivot['Export_Capacity_N'].fillna(0.5)
        
        energy_df = pd.merge(
            energy_df,
            prod_pivot[['Country', 'Year', 'Kappa_Energy']],
            on=['Country', 'Year'],
            how='outer'
        )
        
        print(f"  ✓ κ 计算完成: {energy_df['Kappa_Energy'].notna().sum()} 条记录")
        
        # 计算 V_Energy
        print("  计算 V_Energy...")
        
        def calc_v_energy(row):
            components = {
                'Theta': row.get('Theta_Energy'),
                'I': row.get('I_Energy'),
                'Kappa': row.get('Kappa_Energy')
            }
            
            valid = {k: v for k, v in components.items() if pd.notna(v)}
            if len(valid) == 0:
                return np.nan
            
            weights = {'Theta': 0.40, 'I': 0.35, 'Kappa': 0.25}
            total_weight = sum(weights[k] for k in valid.keys())
            if total_weight == 0:
                return np.nan
            
            v_value = sum(components[k] * weights[k] for k in valid.keys()) / total_weight
            return v_value
        
        energy_df['V_Energy'] = energy_df.apply(lambda row: calc_v_energy(row), axis=1)
        
        print(f"✓ V_Energy 计算完成")
        print(f"  有效记录: {energy_df['V_Energy'].notna().sum()}")
        print(f"  V_Energy 范围: {energy_df['V_Energy'].min():.3f} - {energy_df['V_Energy'].max():.3f}")
        
        self.data_dict['energy_v'] = energy_df[[
            'Country', 'Year', 'Theta_Energy', 'I_Energy', 'Kappa_Energy', 'V_Energy'
        ]]
        return energy_df
```
