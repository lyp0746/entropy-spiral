# 方法论说明（METHODOLOGY）

本书的核心方法论立场是：**在承认全局不可预测的前提下，做诚实的局部诊断。**
本文件说明这一立场如何落实为可复现的操作。

## 1. 为什么放弃“预测何时崩溃”

周期论要求三个前提：系统回到同一状态、周期长度近似常数、外部冲击不改变回归结构。
三者逐一被第 1 章否证。取而代之的是一个较弱的承诺：

> 我们可以在**有限窗口、有限变量、有限分辨率**下描述系统的脆弱性，
> 但不能给出崩溃的时点。

这一替换不是修辞，而是把研究目标从“点预测”改为“**条件情景 + 监测指标**”
（第 7—8 章），并接受由此带来的**否定性结果**。

## 2. 三层框架与三根不可逆轴

| 层 | 内容 | 时间尺度 |
|---|---|---|
| 底层 | 地缘与人口分布（外生） | 世纪—千年 |
| 中层 | 制度、文化、信息传递（传导） | 十年—百年 |
| 上层 | 政治实体与吸取—重置循环 | 年—十年 |

在此之上识别三根不可逆轴：Θ（租佃份额）、I（组织复杂度，条件轴）、κ（地缘耦合）。
轴的判定标准见定义 2.1（长期单向、回归成本极高、与脆弱性正相关）。

## 3. 证据等级

全书对每个数字标注等级，**等级决定它可以被怎样使用**：

| 等级 | 含义 | 允许的用法 |
|---|---|---|
| **A** | 官方统计，可由 API/公开数据复现 | 精确引用、趋势与显著性 |
| **B** | 公开估算或数据库编码，口径稳定 | 方向与量级，注明口径 |
| **C** | 稀疏或构造性序列、定性示意 | 仅用于方向判断，不作精确引用 |

自动检出所有 C 级片段见 `校对清单.md` 表 A4。

## 4. 六重代理系统（第 4 章）

Θ 不用单一指标度量，而用六个代理分别检验：
盐铁专卖占比、财富/收入不平等、金融利润份额、AI 垄断集中度、企业规模分布、债务/GDP。

方法要点：
- 每个代理先做**方向检验**（Spearman ρ + Theil–Sen 斜率），再做**合成与留一测试**。
- 报告**代理相关矩阵**，明确“六重 ≠ 六倍独立证据”。
- 把最强的否定性结果（P1 盐铁占比反向、2015 年后财富份额走平）写入正文，而非脚注。

## 5. 中层机制（第 3.8 / 3.10 / 4.10 节）

- **反馈速度与同构性（定义 3.4 / 3.5，第 3.8 节）**：反馈环指数 Ω 与“同构脆弱”假说；
  冲击走快通道、纠错走慢通道，传播与纠错的速度不对称即失配之源。
- **拓扑中介（表 5.3，第 5.3 节）**：I 不直接进入寿命方程，而是通过反馈拓扑（Ω）中介；
  这解释为何混池回归中 I 的净效应≈ 0（登记为 P5.4）。
- **三案例拓扑诊断（第 8.2—8.4 节，质量 C 框架应用）**：能源＝两层（mesh 价格 + sequence 物理），
  δ≠0；AI＝序列链 + 单点集中；债务＝制度相关 δ（市场层能否约束财政层）。

- **超稳定结构（定义 3.3）**：重置清除状态，不改变边界，因此吸引域固定而回归时间可变。
- **精英二分（定义 4.4）**：收益来源分化为生产性与寄生性，配置由 r/π 决定。
- **权俘获 Φ（定义 4.5）**：评价权被在位者掌握的程度，选拔质量 q = q₀(1 − Φ)。
- 机制链：`Θ↑ → r/π↑ → 寄生端倾斜 → Φ↑ → q↓ → 压力释放失效 → 阈值重置`。

## 6b. 真实数据升级记录

- **κ 贸易／金融维度**：World Bank WDI（`fetch_kappa_wdi.py`）——质量 A。
- **κ 关键商品进口集中度**：UN Comtrade HS-6 按来源国分解，计算 HHI（`fetch_hhi_comtrade.py`，`data/hhi_chokepoints.csv`）——质量 A。
  结果修正了“中国 κ 最高”的指示性叙述：中国芯片进口 HHI（0.213）低于日本（0.404）与印度（0.333）；
  极端集中出现在稀土（美国 0.975、印度 0.978，几乎全部来自中国）。
- **能源纠错（δ≠0）**：Eurostat nrg_ti_gas（`fetch_eu_gas_dependence.py`，`data/eu_gas_ru_share.csv`）——质量 A。
  欧盟自俄气份额 41.0%（2020）→ 9.3%（2023）：直接否证“能源无纠错通道”。
- **债务 r−g**：FRED 长期国债收益率 + World Bank 增长／平减指数（`fetch_debt_rg.py`，`data/debt_rg.csv`）——r/g 质量 A。
  墨西哥 r−g = +2.10pp（强制纠错）；美/英/日/德为负但 2024 年幅度收窄（美 −1.14pp、英 −0.92pp）。
- **债务/GDP**：IMF WEO（经 FRED，`fetch_debt_gdp.py`，`data/debt_gdp.csv`）——质量 A。
  日本 240% 但 r<g + 央行吸收 → δ 最低；墨西哥 58% 但 r>g → δ 最高：触发纠错的是 r−g，不是债务水平。
登记簿的作用是把“解释”变成“可被否证的承诺”。

## 7. 可复现性

- 正文用占位符 `{{D:key}}`；数值集中在 `data/injected.json`；构建时自动注入。
- 所有分析脚本位于 `analysis/`，结果写入 `analysis/results/`，图写入 `assets/charts/`。
- 重跑：`bash scripts/update-data.sh`（数据）→ `bash scripts/build.sh`（成书）。
- 校对：`bash scripts/validate.sh`（术语、编号、交叉引用、EPUB 结构）。

## 8. 已知边界

1. 社会熵只提供**方向**，不提供数值。
2. 相空间、Lyapunov 指数等是**类比**，不是社会系统的自然定律。
3. 跨时代 Θ 水平不可直接比较（抽取对象、货币化程度、数据形态不同）。
4. 代理高度共线，合成指数的“稳健”不等于“证据充足”。
