复现
----
1) 创建 .env.comtrade（含 COMTRADE_KEY=...，勿提交）
2) python analysis/fetch_kappa_wdi.py
3) python analysis/fetch_hhi_comtrade.py
4) python analysis/fetch_eu_gas_dependence.py
5) python analysis/fetch_debt_rg.py
6) python analysis/make_figures.py && python analysis/audit.py
7) bash scripts/build.sh   # 或 scripts/release.sh
