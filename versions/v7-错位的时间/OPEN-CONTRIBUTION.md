# 欢迎补充数据（Open Contribution Guide）

《错位的时间》把「数据缺口」视为公开的研究议程，而不是作者的私产。欢迎以以下方式参与。

## 可以贡献什么

1. **制度反应时间案例库**
   对任一国家／任一政策事件，记录三个时间戳并给出来源：
   `信息首次出现` → `决策公布` → `开始执行`。
   每条一行，注明来源链接与质量评级（A/B/C）。

2. **信息失真的公开代理**
   在无法取得内部数据时，用可公开观测的代理替代，例如：
   统计口径修订幅度、上报数据与独立抽查的偏差、历史解密对照。

3. **知识验证追踪**
   对 AI 生成论文／成果的「声称—验证」过程做长期记录，形成时间序列。

4. **跨域指标**
   医疗、气候、心理、教育、能源、知识六个领域的「变化尺度 vs 适应尺度」数据。

## 贡献格式

- 原始数据：`data/`（`year,value` 两列的 CSV 即可）
- 注入正文：在 `data/injected.json` 增加 `key`，正文用 `{{D:key}}` 引用
- 表格：`<table class="nat">` + `<caption class="cap">表 X.Y</caption>` + 紧随的 `<div class="datasrc">`（来源、质量等级、口径说明）
- 质量等级：**A**＝官方可复现；**B**＝稳定公开估算；**C**＝稀疏/构造，仅方向

## 评审与合并

1. 提交时附来源链接与口径说明；
2. 交叉核对：同一指标至少两个独立来源，或注明单一来源的限制；
3. 若新旧数据冲突，**保留冲突并公开**，不取平均掩盖；
4. 合并后运行 `python analysis/audit.py` 与 `bash scripts/validate.sh`。

## 不接受的贡献

- 无法追溯来源的数值；
- 把 C 级构造序列当作 A 级实测；
- 为让结论更「整齐」而选择性报告。

> 一条原则贯穿始终：**把「没测到」和「测到了」一样认真地记录。**
