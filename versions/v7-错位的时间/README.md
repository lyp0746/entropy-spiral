# 错位的时间 · 归档快照

**社会系统的熵增螺旋、制度错配与可控性边界**　·　李毅芃

---

本目录是《错位的时间》一次完整重写后的**归档快照**，用于长期保存与追溯。
正式发布产物（PDF / EPUB / HTML）见 `release/`；本快照保存源文件与生成脚本。

## 内容

| 路径 | 说明 |
|---|---|
| `source/` | 书稿源文件（`book.json`、`parts.json`、前置、15 章正文、结语、附录 A—H） |
| `cover.svg` | 封面矢量图 |
| `fig-*.svg` | 全书插图（矢量） |
| `build_book.py` / `build_epub.py` | 组装 HTML + PDF、生成 EPUB 的构建脚本 |
| `analysis/migrate_v7.py` | 结构迁移与“章节语义重编号”脚本（旧结构 → 本版结构） |
| `analysis/fix_labels_v7.py` | 案例/警告/命题/情景标签的同步重编号脚本 |
| `DATA-GAPS.md` | 数据缺口清单（已获取 / 可获取 / 结构性不可得） |
| `OPEN-CONTRIBUTION.md` | 开放贡献指南 |

## 本版要点

- **五部分、十五章 + 开篇 + 结语 + 附录 A—H。**
- 时间维度自始至终是中心线索，而非后补：
  第 4 章“时间层级的社会学”为理论中枢；第 5—7 章分别以时间视角重读
  Θ（攫取加速度）、I（反应时间）、κ（传导加速）。
- 核心变量：时间错配 `τ = T_min / T_available`，
  可控性 `C = T_policy / T_threat = 1/τ`，
  有效适应能力 `AC_有效 = AC_名义 × min(1, C)`。
- 新增内容：开篇故事；知识生成与知识认可案例；
  “认知的时间错配”（个人的 I 效应）；
  “发现的逻辑：反例如何驱动理论拓展”；
  控制论基础与“优雅降级”；I 的四层含义；
  六大领域扩散（医疗、气候、心理、教育、能源、知识）。
- **附录 H（可得数据补充与数据缺口）**：开放数据库可得指标总表、四案例公开事件时间线、
  数据可得性评级与缺口清单；“不可得”被明确登记并给出获取路径。
- 正文不含任何版本相对语言（如旧版号、第几版）；版权页与引用格式统一为“初版”，
  日期取真实完成日期（单一来源 `book.json` → 版权页）。

## 复现

```bash
pip install -r requirements.txt
bash scripts/build.sh        # 校对 → 印刷版 PDF → 电子阅读版 PDF → EPUB
bash scripts/release.sh      # 组装发布包
```

字体：中文宋体（SimSun）+ 西文 Times New Roman；标题微软雅黑 / Arial。
默认管线为 HTML → PDF（Chrome headless），无需 LaTeX。
