附录 I　事前登记清单

本附录把正文第 11.7.1 节的三项盲测（B1、B2、B3）固化为一份可追溯的事前登记清单。它在本书发布之前写定，观测后不得回调；其唯一目的是让 τ 与 C 从“事后叙事”变成“可被证伪的事前判断”。登记的价值不在于预测的准确，而在于它使框架可被反驳。

I.1　登记规则

  • 时点：登记日期为本书完成日期（见版权页）；任何后续修订不得改写已登记的预测，只能在新增行中登记新命题。
  • 信息边界：登记所用的 Tmin、Tavailable、阈值与数据来源，只能取自事件发生之前可得的公开信息。
  • 判定：以“方向”而非“点值”判定——预测“C < 1 与否”，而非“C 等于几”。这与命题 4.1（量纲不可通约）一致。
  • 核销：到预计完成年（2027）对照观测变量核对；命中与落空均计入，不因结果不利而删改。

I.3　与第 11 章登记簿的关系

本附录只登记 τ 与 C 的盲测；完整的可证伪命题集（含 P 编号）仍见正文表 11.4。两者的分工是：表 11.4 登记机制性命题（“κ 继续上升”“一致性先于耦合回落”等），本附录登记“框架能否事先判断来不来得及”。若本附录的三项盲测半数以上落空，则 τ 框架必须被削弱——这正是把框架写成可被推翻的形式的意义。

I.4　核销进度与更新记录（可观察的事实）

事前登记的价值只有在“事后真的去对”时才成立。为避免“登记后遗忘”或“只报命中、不报落空”，本节把核销过程本身也变成可观察的记录：每项盲测标明当前状态、已收集到的信息、下一次核对日期与负责人。截至本书完成日期（2026-10-11），三项盲测均未到可判定时点，因此状态一律为“未揭晓”（0/3 已核销）——这是事实陈述，不是拖延。

这一小节回应了一个常见的质疑：“你说你诚实，凭什么相信？”答案不是再写一句承诺，而是提供一张已开始记录、且允许被外部核对的进度表。若到 2027 年本表仍未更新，读者可以据此判断登记是否只是修辞。登记要迁移到公开平台（OSF 或本仓库 GitHub Issues），迁移后此表将改为指向外部时间戳记录；迁移前，以本附录与仓库提交历史为登记依据。

  • docs/preregistration/registry.json —— 登记本体（预测、观测变量、成功标准、否定条件、基线）。
  • docs/preregistration/checkups.csv —— append-only 核销账本：第一行为基线，之后每次核对追加一行，绝不改写旧行。

  • .github/ISSUE_TEMPLATE/blind-test-checkup.yml —— 每次核销开一个 issue 的模板，四点分开报告。
