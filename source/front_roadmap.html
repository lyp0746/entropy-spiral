理论地图　一份给读者的路线图

本章不承担论证，只承担一件事：让读者在前言之后、进入正文之前，就能用非技术的语言说清楚本书的核心假设与四个变量，并知道哪些结论强、哪些结论弱。本书的论证路径是螺旋式递进的——“问题→深化→再问题”——这种结构利于思想的展开，却容易让读者在细节中迷失。因此，请把本章当作一张地图：它先标出地形，再指出哪条路值得走、哪条路有塌方。

0　三类概念：读任何结论之前，先看它属于哪一级

1　一句话的假设

本书的核心假设只有一句：

现代社会的主要脆弱性，不只是“结构坏掉了”，而是“结构变坏的速度，超过了制度作出回应的速度”。

把这句话写成公式，就是时间错配与可控性：

τ = Tmin / Tavailable，　　　C = Tpolicy / Tthreat = 1 / τ(0.1)

其中 Tmin（=Tpolicy）是达成并执行一次有效协调所需的最小时间，Tavailable（=Tthreat）是系统在越过不可逆阈值之前真正可用的时间。当 C < 1，问题不再是“有没有能力”，而是“能力来不来得及被使用”。本书的全部新意，几乎都可以由这一句话推出。

1.1　本书假设的读者是谁——以及不是谁

为了避免一种隐性的筛选，这里明确说明本书的预设：

  • 本书假设你：能接纳“可能来不及”这个结论；不追求“完美控制”的幻觉；愿意承认“我不知道”的限制。
  • 本书不假设你：必须左倾或右倾；必须是技术悲观主义者；必须已经相信复杂系统理论。

如果你的立场与上面相反，本书仍然有内容对你有用吗？明确的回答是：也许，也许不——这取决于你如何对待“被推翻的假设”。本书不打算招募盟友，只想把话说清楚，让不同立场的人都能检验它：每个关键结论都附有否定条件（第 11 章），而不是靠语气取胜。

3　框架如何工作：一条五步流水线

本书不是一堆互不相关的章节，而是一条固定的诊断流水线。理解它，就能理解各章的位置。

  1. 诊断结构（第 5—8 章）。测量三根轴 Θ（攫取）、I（协调时间）、κ（耦合），合成脆弱性指标 V。输出：系统现在有多脆弱。
  2. 诊断时间（第 4、10、13 章）。测量 τ 与 C，判断系统还剩多少时间。输出：来得及吗？
  3. 做出判断（第 11 章）。用“局部可描述性”的三层约束与五步检验，判定结论属于“可描述／条件可描述／不可描述”哪一档。
  4. 提前登记（第 11、12 章）。把 if–then 条件与否定条件在看到信号之前写下来，观测后不改。
  5. 若 C<1（第 12、13 章）。转入“暴露管理”与“优雅降级”：不追求完美控制，而是预先决定放弃什么、保护什么。

这条流水线的一个关键性质是：第 2 步（时间）可以否决第 1 步（结构）。一个结构上很脆弱的系统，若时间充裕，仍可能自救；一个结构上不算脆弱的系统，若时间不够，也会失败。这正是本书与“脆弱性清单”类研究的根本区别。

4　本书的论证顺序（以及为什么它看起来是“回旋”的）

为什么这本书看起来有点迂回。本书刻意采用“从问题出发、逐一追踪失败、让结论被迫显现”的策略，而非“先给结论再倒推证据”。代价是前中段较抽象；收益是结论由读者在论证末端自己“被迫”得出。若你在第 5—6 章感到迷茫，这不是你的错，是设计使然——可坚持到第 9 章，或直接跳到第 10 章。

本书的结构是螺旋式的：第 1—3 章立论，第 4—9 章验证与诊断，第 10—12 章用应用测试反过来动摇框架，第 13—15 章把动摇升华为新理论（可控性边界与 I 的再定义）。这种“先相信、再怀疑、最后重建”的顺序，是为了让每一步的怀疑都有实据，而不是先立后破的空转。代价是：核心结论要读到中后段才完全显形。

8　观测窗口、证据等级与写作约定

为避免全书出现“不同章节暗示不同观测窗口”的混乱，本书在此统一声明：

  • 主观测窗口为 1980—2024（共 45 年）。这是“金融化与全球化急速推进”的时段，也是本书多数当代代理的覆盖区间。超出该窗口的数据——例如前现代中国的盐铁序列（−200—1911）、Seshat 的政体存续时长（−202—1912）、以及个别 2025—2026 年的最新读数——均在正文中以脚注或口径说明标注为“历史延伸”或“最新数据”，不计入主观测窗口。
  • 证据分三级。A＝官方统计可直接复现；B＝公开估算、口径稳定；C＝稀疏或构造性序列，仅可用于方向判断。C 级输入不得成为结论的唯一支撑（定义 11.1）。全书 C 级内容集中于附录 C 表 C.2。
  • 证据等级 × 概念等级，双重标注。凡标注证据等级（A/B/C）处，同时标注概念等级（甲／乙／丙，见表 0.0a）：A/B/C 说明“数据有多硬”，甲／乙／丙说明“概念能不能被直接读到”。例如一处“证据等级 C”的机制推导，若使用的是丙类概念（I、τ、C），结论句必须同时能读出“事后推断、只作序数”这一限制。
  • 写作约定（一种刻意的分工）。第 1—3 章与结语、后记使用论辩与散文笔法，用于提出直觉与价值立场；第 4—15 章中的机制推导使用可检验的技术语言，凡出现隐喻，均随即给出精确表述（例如“时间的重力”一律改写为“Tpolicy 随制度层级近似线性增长，而 Tthreat 随耦合度下降，二者之差即时间维度的不对称”）。隐喻只承担启发，不承担论证。
  • τ 与 C 的用途限定。二者是事后诊断与序数比较工具，不是事前预测工具。本书不提供、也不建议用 τ 或 C 去预测具体事件的时点；它们只回答“相对而言，哪个系统更来不及”。（详见 §4.7、§10.8、§13.2）
