# 修订说明

## 本版说明（2026-10-11）

**定位。** 一部关于社会系统脆弱性与"时间错配"的学术专著。全书的核心主张是：
脆弱性除了结构来源之外，还有一个独立的时间来源——多个社会子系统的时间尺度无法
对齐，使"是否来得及控制"成为一个与"有多脆弱"不同的问题。

**双轨同版。** 共同入口（开篇、前言、《十分钟读懂本书》、《理论地图》）之后分为两条路径：
普通读者走**快速路径**（每章“快速理解”与“关键产出”框）；学术与实践读者再走**完整路径**
（带 ⚙️ 标记的技术小节与附录工具）。《理论地图》开头先给出**三类概念（甲／乙／丙）与使用规则**。

**全书结构（五部分、十八章）。**

- **第一部分　理论转向与时间问题的发现（第 1—4 章）**：从周期论的破产出发，
  转向相空间中的螺旋；给出螺旋的时间结构；并以"时间层级的社会学"作为理论中枢。
- **第二部分　三个核心变量的时间重读（第 5—7 章）**：Θ（租佃份额）的加速度、
  I（组织复杂度）作为反应时间、κ（地缘耦合）的传导加速。
- **第三部分　综合诊断框架（第 8—9 章）**：脆弱性指标 V，以及从芯片到知识的
  四个案例面板；显式引入时间维度指标（相位错配、适应速率比、路径锁定）。
- **第四部分　应用与边界（第 10—11 章）**：三个情景的实装检验、
  发现的逻辑与局部可描述性的操作定义。
- **第五部分　在不可控中行动（第 12—18 章）**：政策议程；可控性边界与控制论基础、
  五类边界与“优雅降级”、**学习滞后（二阶时间错配 ρ_learn）**、重新定义 I、向医疗、
  气候、心理、教育、能源、知识系统六个领域的扩散；以及**时间预算的制度实装（金融／医疗／气候）
  与个人层行动工具**。
- **结语与后记**：结语《承认与启蒙》；**后记《方法论的自限性与伦理立场》**——
  说明框架为何不替各领域给出方案（逻辑必然而非谦虚）、为何“学习本身也有时间约束”、
  以及“认识自己、认识环境、在边界内合作”的伦理立场。
- **附录 A—I**：数学补充、跨领域方法、数据源与再现性、粮食与能源检验、
  术语表、应用工具包、情景库、可得数据补充与数据缺口，以及**附录 I 事前登记清单**
  （可追溯的盲测登记表）。

**立即可得的数据。** 附录 H 把开放数据库（World Bank / IMF / WID / UN Comtrade 等）
中可直接获取的指标集中成总表（H.1—H.2），并给出四个案例的公开事件时间线
（H.3—H.6）。**无法获取的指标被明确登记为“数据缺口”**（H.3，独立版见
《数据缺口清单.md》），说明原因与获取路径，而不是用构造序列填充。
欢迎通过《欢迎补充数据.md》提交补充。

**核心变量。**

- 时间错配　τ = T_min / T_available
- 可控性　　　C = T_policy / T_threat = 1 / τ
- 有效适应能力　AC_有效 = AC_名义 × min(1, C)

**方法与边界。** 全书不预测崩溃时点，只做受到明示约束的局部诊断；证据分 A/B/C 三级，
C 级仅作方向判断；并提供一份可证伪的命题登记簿与一份事前登记清单。

A4 单栏，10.5pt，1.5 倍行距。三种产物（印刷版 PDF、电子阅读版 PDF、EPUB 3）
